## 如何安装 / 使用
1. 把 `skills/my-first-skill/` 目录复制到你 TRAE 工作区的 `.trae/skills/` 下。
2. 最终路径应为：`.trae/skills/my-first-skill/SKILL.md`。
3. 在 TRAE 中即可通过 `/my-first-skill` 触发（或按 description 描述的场景自动调用）。

## 目录结构
```
.
├── README.md
└── skills/
    └── my-first-skill/
        └── SKILL.md
```

## 备注
- 文件名必须是大写的 `SKILL.md`。
- `SKILL.md` 开头必须有 `---` 包裹的 frontmatter（`name` + `description`）。
